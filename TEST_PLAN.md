# У Илем 4.1: план функциональной проверки

Цель: проверить не только запуск страницы, но и связность игровых систем. До завершения первичного прогона контрольный HTML не изменять.

## 1. Запуск и целостность
- [ ] Файл открывается в актуальном Chrome/Edge без белого экрана.
- [ ] Нет критических ошибок JavaScript в DevTools Console.
- [ ] Нет обязательных ресурсов, которые не загружаются (404/CORS/blocked).
- [ ] Интерфейс помещается в окно, основные панели доступны.
- [ ] Повторное открытие не приводит к потере или дублированию состояния.

## 2. Карта и объекты
- [ ] Отображается утверждённая карта и правильная композиция территории.
- [ ] Озеро, дороги, лес, участки, теплица и площадки зданий на своих местах.
- [ ] Здания не пересекаются геометрически и не перекрывают друг друга ошибочным порядком глубины.
- [ ] Выбор каждого объекта карты открывает панель именно этого объекта.
- [ ] Кнопки карты работают, нет невидимого слоя, блокирующего клики.
- [ ] Приближение/отдаление и перемещение камеры не ломают выбор объектов.

## 3. Объекты и строительные этапы
- [ ] У объекта отображаются его собственные характеристики и этапы.
- [ ] «Выполнить этап» запускает этап выбранного объекта, а не общий список.
- [ ] Нельзя выполнить этап без необходимых ресурсов/инструментов.
- [ ] Выполнение этапа меняет состояние объекта и списывает ресурсы/деньги корректно.
- [ ] Повторное нажатие не создаёт дубликат выполненного этапа.

## 4. Задачи и календарь
- [ ] Задачу можно создать, назначить ответственному и сохранить.
- [ ] «Добавить в задачи» переносит этап в общий список без дублей.
- [ ] «Утвердить» сохраняет решение и закрывает окно только после успешного сохранения.
- [ ] При ошибке сохранения окно остаётся открытым и показывает причину.
- [ ] «В план» помещает задачу в календарь и закрывает/обновляет окно ожидаемым образом.
- [ ] Задача из календаря видна в общем списке и не дублируется.
- [ ] Недостаток ресурсов приостанавливает задачу с понятным уведомлением.

## 5. Склад, закупки и финансы
- [ ] Остатки склада отображаются корректно.
- [ ] Покупка списывает деньги и увеличивает нужный остаток.
- [ ] Возврат/отмена консолидированной закупки восстанавливает деньги и остатки ровно один раз.
- [ ] Дефицитные ресурсы блокируют соответствующие работы.
- [ ] Доходы, расходы, бюджет и резерв не расходятся между экранами.
- [ ] История операций не теряет и не дублирует записи.

## 6. Команда и управление
- [ ] Назначение ролей и ответственных сохраняется.
- [ ] Исполнители получают задачи, статусы и сроки.
- [ ] Завершение задачи отражается в общем состоянии проекта.
- [ ] Сообщения команды и важные уведомления не повторяются бесконечно.
- [ ] Пауза/возобновление задач работает предсказуемо.

## 7. Ollama и чат
- [ ] Интерфейс корректно показывает подключение/отсутствие Ollama.
- [ ] При доступном Ollama отправляется запрос и приходит ответ.
- [ ] При недоступном Ollama приложение не зависает и показывает понятную ошибку.
- [ ] Чат не выдаёт ложное подтверждение действий, которые не были сохранены.

## 8. Сохранения
- [ ] Автосохранение срабатывает после значимых изменений.
- [ ] Ручное сохранение создаёт слот/обновляет выбранный слот.
- [ ] Загрузка слота восстанавливает карту, задачи, ресурсы и настройки.
- [ ] Перезагрузка страницы не сбрасывает сохранённую игру.
- [ ] Старое/повреждённое сохранение обрабатывается без падения приложения.

## 9. Сезоны, погода и освещение
- [ ] Смена сезона/погоды обновляет визуальное состояние без ошибок.
- [ ] Освещение переключается и отражается в энергопотреблении, если оно моделируется.
- [ ] Растительность и обслуживание территории меняются во времени, если эти механики реализованы.
- [ ] Нет существенного падения производительности при длительной работе.

## 10. Итоговый протокол

Для каждого дефекта записывать: раздел и объект; точные шаги воспроизведения; ожидаемое поведение; фактическое поведение; ошибку Console/Network; критичность (блокер / высокая / средняя / низкая).

Исправления выполнять только в рабочей копии, например в отдельной ветке `audit/4.1`, а `U_Ilem_4_1.html` оставить неизменным эталоном до принятия решения о замене.
