# У Илем 4.1

Рабочая версия проекта на ветке `work/4-1-water-tower-map`.

## Запуск в Windows

1. Убедитесь, что установлен Node.js 20 или новее.
2. Убедитесь, что Ollama запущена и модель `qwen3:4b` установлена.
3. Запустите `start.bat`.
4. Игра откроется по адресу http://127.0.0.1:4173/.

Если используется другая модель, задайте переменную окружения `OLLAMA_MODEL` перед запуском `start.bat`. Сервер использует Ollama на `127.0.0.1:11434`.

Можно открыть [U_Ilem_4_1.html](./U_Ilem_4_1.html) напрямую для просмотра, но чат с Ollama работает только через локальный сервер.

## Файлы

- `U_Ilem_4_1.html` — основная игровая сцена и интерфейс.
- `uilem-ollama-fixes.js` — интеграция чата с Ollama, транзакционное выполнение поручений, защита от повторного выполнения, маркер общего склада.
- `server.js` — локальный HTTP-сервер и безопасный прокси к локальной Ollama.
- `start.bat` — запуск на Windows без npm-зависимостей.
- `TEST_PLAN.md` — функциональный план и протокол проверки.

## Принципы

- Ollama предлагает план и черновики задач, но не меняет напрямую склад, деньги и состояние объектов.
- Поручение сначала проходит согласование. Списание материалов происходит только при выполнении и только после проверки остатков.
- Повторное выполнение завершённого поручения или этапа блокируется.
- Фоновая карта встроена в HTML и при интеграции не менялась.
- Маяк остаётся в существующей точке карты. Общий склад добавлен рядом с ним отдельным объектом-маркером.

## Сборка архива

GitHub Actions создаёт ZIP исходного проекта при обновлении рабочей ветки.

## Проверка

Синтаксис новых JS-файлов проверен. Встроенная карта и маркер Маяка сохранены. Реальный запуск Node-сервера, браузерный прогон и ответ установленной на пользовательском компьютере модели Ollama ещё требуют проверки на этом компьютере.
